# 🐳 DockerLabs Machines

Repositorio personal dedicado a la práctica y documentación de **ciberseguridad ofensiva** mediante máquinas vulnerables de [DockerLabs](https://dockerlabs.es/).

En este repositorio documento las máquinas que voy resolviendo, registrando el proceso de análisis, las técnicas utilizadas, las vulnerabilidades encontradas y las herramientas empleadas durante cada laboratorio.

## 🎯 Objetivo

El objetivo principal es desarrollar experiencia práctica en diferentes áreas de la ciberseguridad, especialmente en:

* 🔎 Reconocimiento y enumeración
* 🌐 Seguridad de aplicaciones web
* 🔐 Autenticación y acceso a sistemas
* 💻 Seguridad en sistemas Linux
* ⬆️ Escalada de privilegios
* 🛠️ Explotación de vulnerabilidades
* 📡 Análisis de servicios y redes
* 📝 Documentación de procedimientos y Write-Ups

## 📂 Organización

Las máquinas están organizadas según su nivel de dificultad:

```text
Dockerlabs-Machines/
│
├── 01-muy-faciles/
├── 02-faciles/
├── 03-medias/
└── 04-dificiles/
```

Cada máquina cuenta con su propio directorio y un `README.md` donde se documenta el proceso de resolución.

## 🛠️ Herramientas

Algunas de las herramientas utilizadas durante los laboratorios:

* Nmap
* Gobuster
* FFUF
* Metasploit Framework
* SSH
* Netcat
* Linux
* Burp Suite
* SecLists
* Vim

La utilización de las herramientas puede variar según los servicios y vulnerabilidades presentes en cada máquina.

## 📚 Write-Ups

Cada Write-Up busca explicar de forma clara:

1. Reconocimiento inicial
2. Enumeración de servicios
3. Identificación de vulnerabilidades
4. Explotación
5. Obtención de acceso
6. Escalada de privilegios
7. Análisis final de la vulnerabilidad

Además, se incluyen capturas y evidencias cuando son relevantes para comprender el procedimiento.

## 🚀 Progreso

Este repositorio se encuentra en constante actualización a medida que avanzo en el aprendizaje y resolución de nuevas máquinas.

El objetivo no es únicamente completar los laboratorios, sino **comprender las vulnerabilidades, las técnicas utilizadas y las razones detrás de cada paso**.

---

> ⚠️ **Aviso:** Este repositorio tiene fines exclusivamente educativos. Las técnicas y herramientas documentadas se utilizan dentro de entornos de laboratorio controlados destinados al aprendizaje de ciberseguridad.
